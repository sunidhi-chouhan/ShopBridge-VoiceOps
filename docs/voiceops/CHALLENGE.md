# Challenge brief: Voice-Driven Agentic Workflow Automation (saved verbatim in substance)

Build a real-time, voice-driven agentic workflow using native audio-to-audio Gemini (Gemini Live API on
Google Cloud) that turns spoken instructions into completed business actions across connected APIs,
ledgers, databases or inventory systems. Action-oriented, not a chatbot.

## Participant must define
1. Target user and setting (who, where: counter, warehouse, field, vehicle)
2. Operational friction (exact manual process automated)
3. Action execution path (speech -> workflow steps -> DB/API action -> spoken confirmation)
4. Commercial viability (measurable ROI, unit economics at scale)

## Key capabilities (judged)
- Native real-time voice: sub-second replies, natural turn-taking, mid-sentence interruption and spoken correction
- Vernacular / code-switched fluency (Hinglish, Tanglish, Indic languages, regional names)
- Tool and API calling to ledgers, inventory, CRM, booking, ticketing
- Multi-step orchestration in one workflow
- Intelligent decision-making (next step from input + context)
- Exception handling: incomplete, ambiguous, duplicate, out-of-policy, low-confidence (noise)
- Human-in-the-loop for approval / authorization / judgment
- Transaction safety: spoken read-back before executing; undo / correct
- Workflow visibility: show agent actions and where a human intervened
- Acoustic / field resilience under noise

## Demo must show
- Live voice with natural turn-taking and at least one interruption or spoken correction
- More than one language or code-switched speech, ideally with background noise
- Multi-step workflow with at least one real backend action (mock acceptable)
- An exception / uncertain input and where a human is required
- Visible response latency and a view of actions the agent took

## Submission must show value
Transactions completed, automation level, time/effort saved, errors avoided, language coverage,
cost per transaction / ROI at scale. (Do not invent numbers: measure them.)

## Bonus (optional)
Classify / summarise / transform spoken contributions for other audiences, languages or channels.
